# Codex 学习日志

这个文件夹用于精简记录每天在 Codex 中询问的问题和学到的内容，也包含一个本地可用的私人日志网站。

## 结构

- `index.html`：Felix的学习日记网站入口
- `styles.css`：网站样式
- `app.js`：添加、修改、删除、导入导出与本机存储逻辑
- `INDEX.md`：按日期索引每天的日志页
- `logs/YYYY-MM-DD.md`：每天一页，标题标明日期

## 使用网站

直接用浏览器打开 `index.html`。日志内容会保存在当前浏览器的本机存储中，可以用“导出”生成 JSON 备份，也可以用“导入”恢复。

推送到 GitHub 后，可以在仓库的 Settings → Pages 中选择从 `main` 分支根目录部署这个静态网站。
